# Public API reports

These reports are generated by API Extractor from the declaration files in each publishable entry
point. They make exported contract changes visible in code review.

After intentionally changing a public API, rebuild and update the snapshots:

```sh
npm run api:update
```

Ordinary validation runs `npm run api:check` and fails when generated declarations no longer match
the committed reports. Astro component props remain covered by Astro typechecking and standalone
demo builds because `.astro` component exports are not TypeScript declaration entry points.
